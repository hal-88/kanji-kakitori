# 漢字 書き取りれんしゅう

漢字テスト（書き取り）に向けた練習アプリ。

1. 問題文の色のついた読みを、ノートに漢字で書く
2. 「こたえを見る」で答え合わせ
3. ○（あってた）／×（まちがえた）で仕分け
4. 「まちがえた問題だけ」で復習。○になった問題はリストから消える

- 6年の漢字45字、熟語をふくむ299問
  - 上：樹 覧 値 源 退 ／ 厳 優 推 貴 策 ／ 縮 棒 熟 尺 寸 ／ 揮 痛 批 傷 若 ／ 閉 遺 翌
  - 下：裏 系 盟 欲 株 ／ 蚕 己 除 仁 泉 ／ 縦 頂 忠 誠 敵 ／ 至 宅 糖 紅 卵 ／ 乳 創
- 問題はたて書き／横書きを切りかえられる
- 記録はその端末のブラウザの中だけに保存（ログイン不要）

問題を足すときは `data.js` の各漢字の `q` の最後に `['文の{よみ}。', '答え']` を追加する。
